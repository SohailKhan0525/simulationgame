# Expansion order

Harbor Market implements ordering, receiving, shelf stocking, customer visits, checkout, receipts, price changes, a shelf upgrade, XP, savings and a guided first shift. A map marks future premises. [Machine-readable backlog](backlog.json)

1. Finish Android acceptance on representative devices, establish the production signer and test two consecutive signed updates with retained saves.
2. Expand retail depth and presentation with queue capacity, aisle navigation, better animations, more characters and mobile profiling.
3. Add Relay Computers and a gaming shop using the retail catalog and shared transaction tests. Add device-specific services as independent operators.
4. Introduce a drivable vehicle, parking and deliveries. Use the logistics loop for dealerships and fuel inventory at a gas station.
5. Add a service-based café/restaurant operator, then hotel rooms and bookings. Integrate property purchases and staff only after separate ownership and capacity tests.
